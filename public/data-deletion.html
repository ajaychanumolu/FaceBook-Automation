User Data Deletion Instructions

Last updated: September 2026

Facebook Automation MVP does not retain personal user profiles beyond transient event logs for real-time automation. To request deletion of any event logs associated with your Facebook interaction:

  1. Navigate to the application Dashboard.
  2. Click the Clear Events button to delete all stored interaction logs.
  3. Alternatively, disconnect your Facebook Page using the Disconnect Page button on the home page.
